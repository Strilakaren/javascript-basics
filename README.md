# JavaScript Basics

My exam submission for PGR102 Introduction to Programming, fall 2022. This was my first programming course, so the repository shows where I started.

The solutions use plain HTML, CSS and JavaScript, as the exam did not allow libraries or frameworks. Open an HTML file in a browser to run it.

| File | Exam task |
|---|---|
| `oppgave1.html` | Countries in the Americas: list, filter and find population statistics |
| `oppgave2.html` | Miaow Miaow meets the fish: a small game where you move a cat with buttons |
| `oppgave3.html` | Art Maker: complete the provided code that builds figures from user input |
| `oppgave4-student1.html` | Last Mission: one of three optional tasks |

The images, starter HTML files and some of the code were provided with the exam. `oppgave4-student2.html` and `oppgave4-student3.html` are unused starter files.
